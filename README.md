# PAUSE

AI 에이전트 실습과 차 한 잔을 묶은 기업 워크샵 사이트. 강사: 한성희 · 이준혁 · 이유진.

- `index.html` — 현재 사이트. 메뉴: 워크샵 · 정기프로그램 · 온라인강의 · 강사 · 도입 문의
  - 홈은 기업 교육 담당자(HR)를 대상으로 씀
  - 온라인강의 상세(`#c-...`)는 광고 착지용 셀링 페이지 (상단 메뉴 숨김, 하단 고정 버튼)
  - 사진은 Unsplash 무료 사진. 파일 안 `PH` 목록의 주소만 바꾸면 실제 사진으로 교체됨
- `classic.html` — 이전 버전(스토어·전자책·저널 포함). `/classic`으로 접속
- `SETUP-AUTH.md` — 카카오·구글 로그인 설정 방법

main 브랜치에 푸시하면 Vercel이 자동 배포합니다.
